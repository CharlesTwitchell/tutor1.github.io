Setup note (remove before publishing): this is a scripted demo so you can see the interaction — it isn't calling a real AI model yet, and the "style instructions" box isn't wired to anything live. To make it real: stand up a small backend (a serverless function works fine) that receives the student's message plus your saved style instructions, sends them to the Claude API as the system prompt, and returns the reply. Keep your API key on that backend only — never in front-end code like this file, since anyone could read it in the browser. Anthropic's docs at docs.claude.com walk through this exact pattern.
