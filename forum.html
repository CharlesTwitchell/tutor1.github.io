Setup note (remove before publishing): this forum is a front-end demo — new threads live in the browser's memory only and disappear on refresh, since there's no shared database behind it yet. For a real, moderated community you have two solid paths: (1) fastest — embed a hosted forum like Discourse, Flarum, or a Circle/Mighty Networks community and link to it from here; (2) custom — have a developer add a small backend (e.g. Supabase or Firebase) so posts persist and users can sign in. Either way, plan for basic moderation tools before opening it to real users.
