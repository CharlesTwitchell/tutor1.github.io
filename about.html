How I teach

ADHD isn't a focus problem, it's an interest and reward-signal problem — so I don't ask students to "try harder." I build sessions around structure, novelty, and momentum instead of willpower.

  • Sessions are broken into short sprints with real breaks, not one long grind.
  • We name the actual next physical step, not the vague goal ("open the doc and write one sentence," not "write the essay").
  • Progress is visible — checklists, timers, and small wins we can point to.
  • Nothing is "should." If a strategy isn't working, we change the strategy, not the student.
